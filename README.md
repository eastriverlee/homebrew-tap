# eastriverlee/tap

```sh
brew install eastriverlee/tap/monkeys
```

Or tap it once and use the bare name from then on:

```sh
brew tap eastriverlee/tap
brew install monkeys
```

| formula | what it is |
| --- | --- |
| [monkeys](https://github.com/eastriverlee/monkeys) | environment variables kept in your operating system's keyring, handed to one command at a time |
